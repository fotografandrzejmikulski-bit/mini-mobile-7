# 5G RAN

Physical NR/gNB configuration belongs here after the legal/RF gate is complete.

The software-only validation path uses UERANSIM and does not transmit RF or connect an ordinary Android handset directly to the lab.

Hardware-stage checklist:
- compatible gNB/small-cell;
- compatible handset and USIM;
- correct Open5GS AMF/SMF/UPF configuration;
- lawful spectrum authorization and current UKE conditions;
- controlled test location and RF parameters;
- one-device acceptance test before expanding to seven.
